# JavaScript-project

Quote Generator 
 
 A simple and interactive Quote Generator built using HTML, CSS, and JavaScript. This project displays a random motivational quote every time the user clicks the "Random Quotes Generator" button.

 🚀 Features

Generate random motivational quotes.
Clean and simple user interface.
Built using vanilla JavaScript.
Beginner-friendly project.
Fast and responsive.

🛠️ Technologies Used
HTML5
CSS3
JavaScript (DOM Manipulation)
